Welcome to the official repository of **Costanera Apartments**, the best boutique accommodation in the heart of Punta Arenas, Chilean Patagonia. This project is built with **Astro** and **React**, designed to offer a fast, modern, and multilingual user experience.

## 🌟 Features

- 🚀 **Performance**: Perfect Lighthouse score thanks to Astro.
- 🌍 **Multilingual**: Native support for Spanish, English, and Chinese.
- 📱 **Responsive**: Design optimized for mobile and desktop.
- 📍 **SEO & GEO**: Optimized for search engines and generative engines with Schema.org.
- 🎨 **Premium Aesthetics**: "Terracotta Sunset" color palette and smooth animations with Lenis.

## 🛠️ Technologies

- [Astro](https://astro.build/) - Web framework for speed.
- [React](https://reactjs.org/) - For interactive components (Gallery, Maps).
- [GSAP](https://greensock.com/gsap/) - High-performance animations.
- [Lenis](https://lenis.darkroom.engineering/) - Smooth scrolling.

## 🚀 Installation and Development

1. **Clone the repository:**
   ```sh
   git clone https://github.com/JhonRtmls/departamentos-costanera.git
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Start the development server:**
   ```sh
   npm run dev
   ```
4. **Build for production:**
   ```sh
   npm run build
   ```
