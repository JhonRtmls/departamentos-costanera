欢迎来到 **Costanera 公寓** 的官方代码库，这是位于智利巴塔哥尼亚蓬塔阿雷纳斯中心地带的最佳精品住宿。该项目使用 **Astro** 和 **React** 构建，旨在提供快速、现代且多语言的用户体验。

## 🌟 特性

- 🚀 **性能**：得益于 Astro，Lighthouse 评分接近完美。
- 🌍 **多语言**：原生支持西班牙语、英语和中文。
- 📱 **响应式**：针对手机和桌面设备优化的设计。
- 📍 **SEO & GEO**：通过 Schema.org 针对搜索引擎和生成引擎进行了优化。
- 🎨 **高级美学**：“Terracotta Sunset”调色板和 Lenis 的平滑动画。

## 🛠️ 技术栈

- [Astro](https://astro.build/) - 追求速度的 Web 框架。
- [React](https://reactjs.org/) - 用于交互式组件（画廊、地图）。
- [GSAP](https://greensock.com/gsap/) - 高性能动画。
- [Lenis](https://lenis.darkroom.engineering/) - 平滑滚动。

## 🚀 安装与开发

1. **克隆代码库：**
   ```sh
   git clone https://github.com/JhonRtmls/departamentos-costanera.git
   ```
2. **安装依赖：**
   ```sh
   npm install
   ```
3. **启动开发服务器：**
   ```sh
   npm run dev
   ```
4. **构建生产版本：**
   ```sh
   npm run build
   ```
