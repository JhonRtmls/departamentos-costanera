Bienvenido al repositorio oficial de **Departamentos Costanera**, el mejor alojamiento boutique en el corazón de Punta Arenas, Patagonia Chilena. Este proyecto está construido con **Astro** y **React**, diseñado para ofrecer una experiencia de usuario rápida, moderna y multilingüe.

## 🌟 Características

- 🚀 **Performance**: Puntuación perfecta en Lighthouse gracias a Astro.
- 🌍 **Multilingüe**: Soporte nativo para Español, Inglés y Chino.
- 📱 **Responsive**: Diseño optimizado para móviles y escritorio.
- 📍 **SEO & GEO**: Optimizado para motores de búsqueda y motores generativos con Schema.org.
- 🎨 **Estética Premium**: Paleta de colores "Terracotta Sunset" y animaciones suaves con Lenis.

## 🛠️ Tecnologías

- [Astro](https://astro.build/) - Framework web para la velocidad.
- [React](https://reactjs.org/) - Para componentes interactivos (Galería, Mapas).
- [GSAP](https://greensock.com/gsap/) - Animaciones de alto rendimiento.
- [Lenis](https://lenis.darkroom.engineering/) - Smooth scrolling.

## 🚀 Instalación y Desarrollo

1. **Clonar el repositorio:**
   ```sh
   git clone https://github.com/JhonRtmls/departamentos-costanera.git
   ```
2. **Instalar dependencias:**
   ```sh
   npm install
   ```
3. **Iniciar el servidor de desarrollo:**
   ```sh
   npm run dev
   ```
4. **Construir para producción:**
   ```sh
   npm run build
   ```

## 📍 Ubicación

Nos encontramos en **Mejicana Nº 1481, Punta Arenas, Chile**. A pasos de la Costanera del Estrecho de Magallanes.
